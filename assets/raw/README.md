# Raw Photo Staging

Drop Alix's original photos into the matching folder below. No need to rename,
crop, or resize anything first — just get them in the right destination
folder and roughly indicate hero vs. homepage vs. gallery shots (see naming
tip per folder). These will be organized, cropped, and optimized when the
site is built.

## Folders

- `hong-kong/`
- `tokyo/`
- `seoul/`
- `mount-kinabalu/`
- `sydney/`
- `about/` — camera photograph for the About Me page

## What each destination folder needs (per PRD section 12)

- **1 hero photo** — the large photograph shown beside the color panel on
  the trip page. Prefix with `hero` if you can (e.g. `hero.jpg`,
  `hero-01.jpg`).
- **3 homepage photo candidates** — options for the single photo used inside
  that destination's puzzle piece on the homepage. Prefix with `homepage`
  if you can (e.g. `homepage-1.jpg`, `homepage-2.jpg`, `homepage-3.jpg`).
  Only one of the three will ultimately be used — having options makes it
  easier to pick the shot that crops well into the puzzle-piece shape.
- **4–5 gallery photos** — everything else for that trip. Any naming is
  fine, e.g. `gallery-1.jpg`, `gallery-2.jpg`, ...

If it's not obvious which photo is meant to be the hero/homepage shot,
just drop everything in and note your preference — Alix or whoever is
uploading can flag favorites in a message instead of renaming files.

## Formats

JPG or PNG both work. HEIC (default iPhone format) is fine too — it'll be
converted during processing.
